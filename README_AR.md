# SHIFA | شفاء — النسخة التجريبية الأولية

هذه حزمة بداية (MVP) لتجربة واجهة API بسيطة لإدارة الإدارات والمهام وقاعدة المعرفة.

## التشغيل المحلي
1. ثبّت Python 3.12 أو أحدث.
2. نفّذ: `pip install -r requirements.txt`
3. نفّذ: `uvicorn main:app --reload`
4. افتح: `http://127.0.0.1:8000/docs`

## النشر التجريبي على Render
- أنشئ Web Service من مستودع GitHub واختر Docker.
- أضف متغير البيئة `DATABASE_URL` كرابط PostgreSQL من قاعدة بيانات منفصلة.
- لا تستخدم قاعدة SQLite للتخزين الدائم على استضافة مؤقتة.

## حدود مهمة
- هذا نموذج تقني أولي، وليس نظام معلومات مستشفى معتمداً أو جاهزاً للإنتاج.
- لا يحتوي على تسجيل دخول أو صلاحيات إنتاجية أو سجل تدقيق مكتمل أو تكامل نفيس/أنظمة المستشفى.
- لا تدخل بيانات مرضى أو هويات أو معلومات صحية حقيقية.
- يلزم مراجعة أمنية وسريرية وقانونية واختبارات واعتمادات قبل أي استخدام مؤسسي.
